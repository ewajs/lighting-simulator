# Atajos de teclado

En Windows y Linux, **Ctrl** en lugar de **⌘**.

| Atajo | Acción |
|---|---|
| **⌘Z** | Deshacer |
| **⇧⌘Z** o **Ctrl+Y** | Rehacer |
| **⌘S** | Guardar la escena en un archivo |
| **⌘O** | Abrir un archivo de escena |
| **⌘D** | Duplicar lo seleccionado |
| **⌘A** | Elegir todas las luminarias, o todos los muebles si hay uno elegido |
| **Supr** o **⌫** | Eliminar lo seleccionado |
| **Esc** | No elegir ninguna |
| **H** | Encender o apagar lo seleccionado |
| **F** | Encuadrar lo seleccionado |
| **W** / **E** | Herramienta Mover / Orientar |
| **Alt** (⌥) mientras arrastrás | Mover sin imán |
| **1** / **2** / **3** | Realista / Arcilla / Iluminancia |
| **0** / **7** / **8** / **9** | Vista 3D / Planta / Frente / Lateral |

Los atajos no se activan mientras escribís en un campo.
