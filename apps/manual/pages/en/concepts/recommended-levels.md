# Recommended levels

How much light is enough? The European reference is **EN 12464-1:2021**,
"Lighting of indoor work places". For each kind of task it sets a minimum
maintained illuminance on the task area, a minimum uniformity and, since
2021, how much light the walls and ceiling must get so the room doesn't look
gloomy.

::: warning Workplaces, not homes
EN 12464-1 covers workplaces. No standard binds a home, which is lit more for
mood than for tasks; these values still make a useful reference for a desk or
a kitchen.
:::

## Some values

| Activity | $\bar{E}_m$ (lx) | $U_0$ | Walls (lx) | Ceiling (lx) |
|---|---|---|---|---|
| Writing, reading, computer work | 500 | 0.60 | 150 | 100 |
| Meeting rooms | 500 | 0.60 | 150 | 100 |
| Reception desk | 300 | 0.60 | 100 | 75 |
| Archives | 200 | 0.40 | 75 | 50 |
| Corridors and circulation | 100 | 0.40 | – | – |

These are **maintained** values (see [Maintenance factor](./maintenance)): what
there must be at the end of the cycle, not when new. The standard allows
raising them through what it calls context modifiers, for example when the
task is critical or the person doing it sees less than normal; for desk work,
up to 1000 lx.

Corridors' walls and ceiling aren't listed because the sources consulted
disagree. The standard covers many more spaces; these are the ones we could
confirm in a published copy of its table.
