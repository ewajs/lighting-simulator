# Keyboard shortcuts

On Windows and Linux, use **Ctrl** instead of **⌘**.

| Shortcut | Action |
|---|---|
| **⌘Z** | Undo |
| **⇧⌘Z** or **Ctrl+Y** | Redo |
| **⌘S** | Save the scene to a file |
| **⌘O** | Open a scene file |
| **⌘D** | Duplicate the selection |
| **⌘A** | Pick all luminaires, or all furniture when a piece is picked |
| **Delete** or **⌫** | Delete the selection |
| **Esc** | Pick none |
| **H** | Switch the selection on or off |
| **F** | Frame the selection |
| **W** / **E** | Move / Aim tool |
| **Alt** (⌥) while dragging | Move without the magnet |
| **1** / **2** | Realistic / Clay |
| **0** / **7** / **8** / **9** | 3D / Plan / Front / Side view |

Shortcuts don't fire while you're typing in a field.
