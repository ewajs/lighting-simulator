# Sample IES files

Real photometric files from manufacturers' public websites, used by the demo
to show IES lighting (ADR 0035). They are copied unmodified. Each manufacturer
reserves all rights; none of their sites has terms specific to photometric
data. The library itself never ships these files: real photometry reaches it
through the host's `PhotometryProvider`.
